Synced Flow is a small, opinionated CSS system for building branded, accessible websites with reusable tokens, layout primitives, native components, recipes, and generated utility CSS.

Synced Flow is created by [Synced](https://syncedco.com), the team behind the design system, CLI, examples, and documentation.

This documentation is organised as a working reference, not a marketing brochure. The left navigation is the source of truth: start with installation, learn the primitives, then use the recipes and references while building.
